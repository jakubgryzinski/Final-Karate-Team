# Final-Karate-Team #

Refreshed website of Karate Team Oborniki. Technologies used in the project were selected for the client's needs. So I used static site generation (Astro) to speed up loading times. For animation I use Framer Motion. The data is downloaded from Dato CMS from where the client can manage the content of the site.
